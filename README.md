##README — Fit Bairro Academia

##1. Sobre o projeto

O projeto Fit Bairro Academia foi desenvolvido pelo Squad 5life como parte do Projeto Integrador do SENAI. Consiste na criação de um site para apresentar a academia, divulgar seus serviços e facilitar o acesso dos clientes às principais informações do estabelecimento.

##2. Objetivo

Desenvolver uma plataforma digital para divulgar os serviços, modalidades, planos e preços da academia, além de facilitar a comunicação e o acesso dos alunos às informações.

##3. Público-alvo e cliente

Cliente: Fit Bairro Academia.

Público-alvo: Pessoas que buscam melhorar a saúde, o condicionamento físico e a qualidade de vida, sem precisar se deslocar para lugares muito distantes.

##5. Organização e planejamento

O projeto foi organizado a partir de uma ficha de briefing, com divisão de tarefas entre os integrantes. O quadro Kanban foi utilizado para distribuir e acompanhar as atividades, enquanto o GitHub registrou as alterações por meio de commits e Pull Requests.

##6.Estrutura das páginas

O site foi dividido em seções para facilitar a navegação e organizar as informações:

* Início: apresentação da academia, logotipo e formas de contato.
* Catálogo: apresentação dos planos, modalidades e preços.
* Sobre: informações sobre a história da academia.
* Contato: informações de contato e formulário para agendamento de avaliação experimental.

##7. Identidade visual

A identidade visual utiliza laranja, preto e branco, com elementos esportivos como halteres e imagens de atletas.

##8. Quadro Kanban

O quadro Kanban foi utilizado para organizar e acompanhar as atividades do projeto, permitindo visualizar as tarefas, identificar seus responsáveis e acompanhar o andamento do desenvolvimento até a conclusão.
